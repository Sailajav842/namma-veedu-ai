# 🏠 Building Planner AI (Namma Veedu AI)

An AI-powered web application that helps users design smart building plans based on their requirements. The platform generates optimized 2D floor plans, interactive 3D house models, construction cost estimations, and connects users with verified civil engineers across Tamil Nadu.

---

## 🚀 Features

- 🤖 AI-powered building plan generation
- 📐 Automatic 2D floor plan creation
- 🏡 Interactive 3D house visualization
- 🏢 Multi-floor support (Ground Floor, First Floor, Second Floor, Terrace)
- 🛏️ Intelligent room arrangement
- 🚪 Automatic door and window placement
- 🧭 Optional Vastu-compliant layouts
- 💰 Construction cost estimation in Indian Rupees (₹)
- 📈 Real-time material price integration
- 👷 Engineer marketplace with booking system
- 📞 Contact engineers through Call or WhatsApp
- ❤️ Save and manage favorite designs
- 📄 Export plans as PDF
- 🌙 Light & Dark mode
- 🔐 Secure authentication using Supabase

## 🎯 How It Works

1. User enters plot dimensions.
2. User selects building type.
3. User enters budget in ₹.
4. AI generates an optimized floor plan.
5. A 3D model is generated.
6. Construction cost is estimated.
7. Users can book verified civil engineers.
8. Plans can be saved and exported.
